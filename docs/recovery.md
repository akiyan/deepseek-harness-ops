# 復旧

## 認証と使用量

- 未ログイン：モデルプロバイダー追加から Sign in with ChatGPT を選び、Continue with ChatGPT を押す。接続済みアカウントのセッション失効：詳細を開き、再接続する。
- ChatGPT プラン利用の同意なし：再接続で利用権限を確認する。API キーへの自動切替は行わない。
- 利用上限：使用量設定を開く。上限だけからリセット時刻を推測しない。
- 一時的なネットワーク障害：接続回復後に再試行する。資格情報を削除しない。
- ログアウトの失効未確認：ChatGPT の接続設定で本アプリを解除する。
- credential store の破損：dsh を停止してから、保護されたローカルバックアップを復元する。ファイルの内容をチャットや GitHub に貼らない。

## アプリの更新失敗

dsh を停止し、更新前に保持したコミットへ切り替え、lockfile どおりに依存をインストールして再ビルドする。認証状態や Session データを古いバックアップで無条件に上書きしない。実装と保存形式の互換性を先に確認する。

## 開発環境

本体は Node.js 24.9 以上を必要とする。検証ホストで一時ディレクトリの容量制限に当たる場合は、空き容量がある専用ディレクトリを作成して TMPDIR を指定する。ビルド出力や認証情報を本リポジトリに置かない。
