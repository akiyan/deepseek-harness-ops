## 認証

- ChatGPT プランは標準 `openai-codex` / `OpenAI (ChatGPT plan)` を使用する
- API キーは既存 `openai` の API キー方式、または明示した `apiKeyEnv: OPENAI_API_KEY` を使用する
- 追加の API キー専用プロバイダーは作らず、標準 `openai` の任意の ChatGPT 認証も変更しない
- 旧独自 `chatgpt`、専用 RPC、独自ログイン画面は退役する
- 資格情報と会話ログは変換・削除しない。旧利用者は再ログインと設定の選び直しが必要。[移行手順](../docs/sign-in-with-chatgpt.md)を参照する

## 運用上の注意

実 OpenAI 認証・課金を伴うモデル呼び出しと、実さくら API の推論は実施しない。ブラウザーの認証フロー確認は実アカウント接続の保証ではない。既存の接続や秘密値は検証に流用しない。

稼働中の別チェックアウトの更新・サービス再起動は本変更の公開とは別に行う。旧 `chatgpt` 設定は標準経路では使われないため、切替時に利用者が `openai-codex` へ再ログインする必要がある。
