# 2026-11-19 さくらのAI Engine プロバイダー

基準は前回と同じ [shiguredo/shiguredo の `8bafe0141eb061c2cde3bae9f315e92f069ca413`](https://github.com/shiguredo/deepseek-harness/commit/8bafe0141eb061c2cde3bae9f315e92f069ca413)。独自差分1コミットに[さくらのAI Engine](https://manual.sakura.ad.jp/cloud/ai-engine/02-howto.html)の同梱ルート `sakura-ai-engine` を加え、コミットメッセージは [変更情報](../dsh_akiyan_fork.md) の URL のみを維持する。

Ollama Cloud と同じ同梱カタログに、接続先・Chat Completions 形式・`max_tokens` 指定と、tool call 対応の6モデルの容量を載せた。同梱モデルの推論レベルを、ルート共通の off 可否からモデルごとの「レベル→送信値」表に変えた。

実 API で計測した推論レベル:

| モデル | 提供するレベル | 計測結果 |
|---|---|---|
| gpt-oss-120b | low / medium / high | `none`・`minimal`・`xhigh`・`max` は 400 |
| preview/DeepSeek-V4.1-Flash-1017 | off / low / high / xhigh / max | `medium`・`minimal` は 400。`none` で思考停止 |
| preview/GLM-5.3-Flash | low / medium / high | `none` でも思考が続く |
| preview/Kimi-K2.7-Code | low / medium / high | `none` で思考過程が本文に混入 |
| preview/Qwen3.6-35B-A3B | off / low / medium / high | `none` で思考停止 |
| preview/gemma-4-31B-it | off / low / medium / high | 既定で思考しない。`none` も受け付ける |

6モデルとも、ストリーミングの tool call、`developer` ロール、`delta.reasoning` の受信を実 API で確認した。

検証結果:

- llm-pi-ai のテスト26ファイル556件が通過した。同梱ルートの解決、モデル一覧と容量、モデルごとの推論レベル、モック先への `max_tokens`・`reasoning_effort` の送信を確認する
- 実 API の e2e 3件（テキスト応答、`max` 指定、gpt-oss へ推論値を送らない既定）が通過した。`SAKURA_AI_ENGINE_API_KEY` がない場合は省略される
- Chromium / WebKit を含む Web テスト2ファイル22件（モデル設定、初回案内）が通過した
- lint、typecheck、test:docs（21 gate）、build（10 gate）が通過した
- 再起動後の Web 画面の起動を確認した。画面からのトークン登録と実推論は行っていない

既知の制限: 入力と `max_tokens` の合計がコンテキスト長を超えると 400 になる。入力の見積もりで出力上限を下げるが、上限付近では外れる場合がある。1リクエストは約5分で打ち切られる。`preview/` モデルは予告なく変更・終了される。
